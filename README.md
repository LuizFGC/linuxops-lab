# LinuxOps Lab

A hands-on Linux laboratory focused on Linux engineering, system administration, and infrastructure automation.

## Objective

Develop practical skills in Linux system administration, networking, security, automation, containerization, and cloud-native technologies through real-world scenarios and hands-on projects.

## Lab Environment

- **CentOS VM:** Linux administration, system configuration, and security experiments.
- **Physical Ubuntu Server:** Remote server administration and infrastructure deployment.
- **SSH:** Secure remote administration and connectivity.
- **Git and GitHub:** Version control and project documentation.
- **Docker:** Containerization and application deployment.
- **Nginx:** Web server and reverse proxy.
